# IT Infrastructure Management System

A Python-based desktop application developed to simplify the management of IT infrastructure records.

## Project Overview

The IT Infrastructure Management System provides a centralized platform for managing organizational IT resources, network devices, technical support requests, and maintenance records.

## Features

- Dashboard and Reports
- User Management
- IT Asset Management
- Network Device Management
- Support Ticket Management
- Maintenance Records
- SQLite Database Integration

## Technologies Used

- Python
- Tkinter / ttk
- SQLite3
- Visual Studio Code
- Git and GitHub
