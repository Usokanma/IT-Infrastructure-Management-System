# IT Infrastructure Management System
## User Guide

### 1. Introduction
The IT Infrastructure Management System is a desktop application designed to support the management of IT resources and infrastructure records within an organization.

### 2. System Requirements
- Windows operating system
- Python 3 installed
- SQLite database
- Required Python libraries used by the application

### 3. Starting the Application
1. Open the project folder.
2. Open PowerShell in the project directory.
3. Run: python app.py
4. Wait for the application window to open.

### 4. Application Modules

#### Dashboard and Reports
Provides access to the application's overview and reporting area.

#### User Management
Provides facilities for managing user records and their organizational information.

#### Asset Management
Used to maintain records of organizational IT assets, including computer equipment.

#### Network Devices
Used to manage network infrastructure records, including routers and switches.

#### Support Tickets
Provides an area for recording and managing IT support requests.

#### Maintenance Records
Provides an area for maintaining equipment and infrastructure maintenance information.

### 5. Database
The application uses an SQLite database stored in:
database/it_support.db

A separate database backup is also maintained.

### 6. Closing the Application
Close the application window normally after completing your work.

### 7. Important
Keep the database folder in the same project directory as the application. Do not rename or delete the database files.
